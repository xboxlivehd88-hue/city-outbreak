# City Outbreak

Browser-based first-person zombie survival game built with Three.js.

## Current Features
- First-person movement and mouse aiming
- Wave-based zombie survival
- Tactical zombie roles (chargers, flankers, interceptors, stalkers)
- Limb damage, detachable arms, limping, corpses
- Multiple weapons with separate ammo pools
- Grenades
- Between-wave shop and progression
- Parked vehicles and city environment

## Project Structure
- `index.html` — game shell
- `src/` — gameplay systems
- `assets/` — future 3D models, textures, sounds, and animations

## Next Goals

2. Add proper GLB/GLTF zombie and weapon models.
